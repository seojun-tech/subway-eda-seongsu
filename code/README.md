# 재현 코드

`python run_all.py` 한 번으로 표와 그림을 만들고, 발표 숫자를 결과 파일과 반올림 자리까지 대조합니다.

- `p0_part1_part2.py`: Part 1 Q1~Q5, Part 2 ②③·종합 (발표 숫자 29개 대조)
- `p2_개강효과.ipynb`: Q1·Q2 심화, 대학 개강 효과 (매칭 비교역, 주별 HAC 회귀, 월별 중앙값). 결과는 `out/opening/`
- `p1_q6_q8.py`: Part 1 Q6~Q8 노선별 질문 (발표 숫자 85개 대조, 수업 파일과 공개 원본이 같은 데이터인지도 확인)
- `s1`~`s4`, `figures.py`, `verify.py`: Part 2 ①, Part 3 성수 분석 (발표 숫자 176개 대조)
- `out/`: 실행 결과 CSV와 그림. 코드를 돌리지 않아도 바로 볼 수 있습니다.

수업 파일은 환승역 노선이 한 이름으로 묶여 있어서, Q6~Q8만 노선이 구분된 공개 원본(`CARD_SUBWAY_MONTH_2019.csv`)으로 계산했습니다. 두 파일은 행 수(107,028개)·순서·승하차 인원이 모두 같고 노선명과 역명 괄호만 다릅니다.

## 주의

- 생활이동은 KT 휴대전화 기반 추정치입니다. 이동 목적 4·5(쇼핑·관광)는 성수·화양에 없어 기타(7)를 여가로 추정했습니다.
- 출발-도착지는 30분 이상 머문 곳만 출발·도착지라 환승역은 출발지가 아닙니다.
- 서울 전체도 2023→2026 더 가까운 이동으로 바뀌어, 성수 값은 같은 날 서울 기준선 대비로 비교했습니다.
- 부천·화성·강원은 행정코드가 바뀌어 구별 비교에서는 두 해 모두 있는 구만 썼습니다.
- 한강로동에는 용산역(KTX)이 있어 '기타' 목적에 기차 이동이 섞였을 수 있고, 명동은 쇼핑 목적 코드가 따로 잡혀 둘 다 참고로만 썼습니다.
